☁️ 云端同步（GitHub 私有 Gist）

数据存到你自己的 GitHub 私有 Gist（文件 film-log.json），永久保存、跨设备同步。Token 只存本机浏览器，不写进网页源码、不上传别处；与你投资看板共用同一个 Gist，互不干扰。
Gist ID 默认已填好。首次只需粘贴你的 GitHub Token，之后手机/电脑填同一个 Token 即可同步。

使用说明

  • 令牌在 GitHub → Settings → Developer settings → Personal access tokens 生成，勾选 gist 权限即可，复制后以 ghp_ 开头。
  • 令牌只存本机浏览器 localStorage，换设备需重新粘贴一次；网页源码里看不到它。
  • 一键上传：把当前本机数据备份到云端（覆盖云端同名文件）。
  • 拉取云端：把云端数据恢复到本机（会覆盖本机，先确认本机没有要保留的新数据）。
  • 网络提示：GitHub 在部分公司网络被屏蔽，若同步失败请换网络（如手机流量 / 家里）。
